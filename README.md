# Hadouken 3D Calc

Calculadora gratuita de precificação para impressão 3D. Roda direto no navegador (HTML, CSS e JavaScript puros), sem instalar nada e sem servidor. Os dados ficam salvos só no navegador de quem usa.

## O que calcula

- Filamento (vários carretéis/cores, com desperdício extra)
- Energia elétrica (consumo em W x tempo x tarifa)
- Desgaste da máquina (depreciação + manutenção por hora)
- Reserva para impressões que falham
- Mão de obra (preparo e pós-processo)
- Embalagem, materiais extras e design
- Despesas gerais, imposto, taxa de marketplace e taxa fixa
- Margem de lucro sobre o preço de venda

## Como publicar no GitHub Pages

1. Crie um repositório novo no GitHub (ex.: `hadouken-3d-calc`).
2. Envie os 3 arquivos: `index.html`, `style.css` e `script.js` (mais este README, se quiser).
3. No repositório, abra **Settings > Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**, branch `main` e pasta `/ (root)`. Salve.
5. Em 1 a 2 minutos o site fica em `https://ThiagoGuterres.github.io/hadouken-3d-calc/`.
